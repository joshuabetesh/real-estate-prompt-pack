# Real Estate AI Prompt Pack: Landing Page

Source for the landing page of the **Real Estate AI Prompt Pack**, a 15-page PDF of 65+ copy-paste prompts for ChatGPT and Claude, written for working real estate agents.

**Live page:** https://joshuabetesh.github.io/real-estate-prompt-pack/

**What's covered:** listing descriptions, social content, buyer and seller scripts, cold outreach (expired, FSBO, SOI), email marketing, CMA narratives, open houses, negotiation, reviews, and a 15-prompt research and due-diligence section.

**Built with:** a single static HTML page (Tailwind via CDN), hosted on GitHub Pages. Checkout runs through Gumroad.

`agent-cover.html` is the PDF cover design.
